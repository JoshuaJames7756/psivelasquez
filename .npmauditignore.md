# Vulnerabilidades conocidas — no accionables

`@vercel/node` (última versión, 16.0.1) arrastra ajv/path-to-regexp/undici
vulnerables como dependencias transitivas de su tooling interno de
desarrollo (@vercel/static-config). No hay versión superior disponible
que las resuelva al momento de este build.

Impacto real: nulo. @vercel/node solo aporta TIPOS TypeScript para las
funciones serverless; el código de estas dependencias no se ejecuta en
el runtime de producción de Vercel (que usa su propia infraestructura
gestionada), solo durante `tsc`/desarrollo local.

Revisar en cada actualización de @vercel/node si se resolvió upstream.

## tar (crítica, vía vercel CLI)

`vercel` (CLI, devDependency para correr `vercel dev` localmente) arrastra
`tar` vulnerable a través de `@vercel/fun` y `@vercel/container`. Mismo
caso: tooling de desarrollo local, nunca corre en el entorno de
producción gestionado de Vercel. Revisar en cada actualización de `vercel`.
